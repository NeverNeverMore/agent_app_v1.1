# 优化项目操作功能及优化选择文件夹功能

## 1. 功能概述

本次优化围绕项目快捷操作、项目目录上下文和会话创建体验展开：

- 项目操作按钮改为快捷菜单。
- 增加项目置顶、编辑、打开主目录、删除项目等操作。
- 保留“会话归档”菜单入口，但暂不实现实际归档逻辑。
- 新增中文项目编辑窗口，统一管理项目名称、主目录和附加目录。
- 历史会话中的文件夹操作改为“编辑主目录”。
- 新对话可以继续使用“选择目录”。
- 项目支持多个工作目录，附加目录可参与搜索、读取和修改。
- 从项目菜单创建新对话时自动继承当前项目主目录和工作区上下文。
- 删除当前项目后自动切换到完全隔离的新空对话。
- 修复项目快捷菜单向右展开时被侧栏或主对话层覆盖的问题。

## 2. 项目快捷菜单

点击左侧项目行右侧的操作按钮后，显示以下菜单项：

1. **新对话**
2. **置顶 / 取消置顶**
3. **编辑**
4. **打开所在文件夹**
5. **会话归档（暂未开放）**
6. **删除项目**

### 2.1 新对话

从某个项目的快捷菜单点击“新对话”时：

- 创建新的空草稿。
- 自动继承当前项目的主目录。
- 自动继承当前项目的附加目录列表。
- 自动切换到聊天界面。
- 用户无需再次手动选择目录。
- 首次发送消息后，会话归档到当前项目下。

### 2.2 项目置顶

- 项目可以置顶或取消置顶。
- 置顶状态保存在会话历史持久化数据中。
- 左侧项目树排序规则为：置顶项目优先，同组内按最近活跃时间排序。

### 2.3 打开所在文件夹

“打开所在文件夹”始终使用项目的主要文件夹路径，通过 Electron 系统文件管理器打开。

该操作不会打开附加目录，也不会修改项目配置。

### 2.4 删除项目

删除项目需要二次确认。确认后：

- 删除项目配置。
- 删除该项目下的会话记录。
- 不删除磁盘上的任何文件夹或文件。
- 如果当前正在使用该项目，右侧主界面自动切换到新的空对话。
- 新空对话不继承被删除项目的主目录、附加目录或项目上下文。
- 删除后可以立即继续输入消息。

## 3. 项目编辑窗口

项目编辑窗口参考提供的编辑项目界面，并使用中文界面。

### 3.1 可编辑内容

- 项目名称。
- 项目主要文件夹。
- 项目附加文件夹。

### 3.2 文件夹列表

- 当前主要文件夹显示“主要”标记。
- 附加文件夹可以点击“设为主要”。
- 切换主要文件夹时，原主要文件夹自动保留为附加文件夹。
- 主要文件夹不能直接移除，必须先将其他文件夹设为主要。
- 附加文件夹可以移除。
- “添加文件夹”调用系统目录选择器。
- 保存时对目录路径去重。

### 3.3 保存规则

- 项目名称不能为空。
- 必须存在有效的主要文件夹。
- 主要文件夹必须属于项目文件夹列表。
- 保存只修改项目配置，不移动、复制或删除磁盘文件。
- 保存后项目树、当前会话目录和工具工作区立即同步。
- 取消操作不会保存编辑内容。

## 4. 历史会话的目录操作

底部文件夹菜单根据会话状态区分操作：

### 4.1 新对话

空草稿显示“选择目录”，可以选择或切换目录。该目录会在首次发送消息时用于创建或复用项目。

### 4.2 历史会话

已经发送过消息的历史会话显示“编辑主目录”。点击后打开所属项目的编辑窗口，而不是只修改单个会话目录。

这样可以保证同一项目下所有会话共享一致的主目录和附加目录，避免上下文散落。

### 4.3 文件管理器操作

底部文件夹菜单中的“在文件管理器中打开”仍然可用，并打开当前项目的主要文件夹。

## 5. 多目录工作区

项目现在可以由一个主要文件夹和多个附加文件夹组成统一工作区。

### 5.1 工具访问范围

以下文件工具支持项目的全部文件夹：

- `file_list`
- `file_read`
- `file_write`

附加目录可以被搜索、读取和修改，和主要目录拥有相同的工具访问能力。

### 5.2 路径访问规则

- 主要目录保持直接使用相对路径的方式。
- 附加目录通过目录名称前缀区分，例如：

```text
附加目录名称/src/index.ts
```

- 文件工具会根据工作区目录列表解析路径。
- 真实路径必须位于已配置的主要目录或附加目录内。
- `..` 路径、符号链接越界和工作区外绝对路径会被拒绝。
- 文件写入继续遵守当前权限模式和请求批准流程。
- Agent 系统提示会列出主要目录、附加目录以及工作区路径规则。

### 5.3 根目录搜索

当从工作区根目录开始列出文件时，工具会返回主要目录和附加目录的入口，并使用目录名称前缀避免同名文件混淆。

## 6. 数据结构变化

项目实体增加以下字段：

```ts
interface Project {
  id: string
  name: string
  folder: string
  sourceFolders: string[]
  pinned: boolean
  createdAt: number
  updatedAt: number
}
```

- `folder`：项目主要文件夹。
- `sourceFolders`：项目全部工作区文件夹路径。
- `pinned`：项目是否置顶。

旧项目数据兼容规则：

- 没有 `sourceFolders` 时，使用旧的 `folder` 自动补齐。
- 没有 `pinned` 时，默认为 `false`。
- 原有会话和项目归属继续保留。

## 7. 菜单层级与显示修复

项目快捷菜单改为固定定位，并根据项目操作按钮的实际屏幕位置计算显示位置：

- 菜单从项目操作按钮右侧展开。
- 菜单不再被会话历史滚动容器裁剪。
- 左侧栏层级高于右侧主对话区域。
- 窗口调整大小或滚动时自动更新菜单位置。
- 菜单支持点击外部区域和 `Escape` 关闭。

## 8. 相关实现位置

- `src/components/Sidebar.tsx`：项目快捷菜单、置顶、新对话和菜单定位。
- `src/components/ProjectEditor.tsx`：项目名称、主目录和附加目录编辑窗口。
- `src/components/Chat.tsx`：新对话选择目录、历史会话编辑主目录和文件夹菜单。
- `src/App.tsx`：项目编辑、删除项目、新建项目会话和主目录打开流程。
- `src/hooks/useConversations.ts`：项目状态、置顶、编辑、删除和新草稿隔离。
- `electron/agentLoop.ts`：多目录工作区提示和工具上下文。
- `electron/tools/pathSecurity.ts`：多根目录路径安全校验。
- `electron/tools/builtins.ts`：多目录文件搜索、读取和写入。
- `src/index.css`：项目快捷菜单、编辑窗口和固定层级样式。
