# 新增知识库功能

## 1. 功能定位

知识库是 Agent 桌面客户端内置的个人资料管理功能，数据保存在本机用户数据目录中，支持管理 Markdown 笔记、导入常见文档，并由 Agent 工具按需搜索和读取。当前实现面向单机个人使用，不包含云同步、多用户权限或协同编辑。

## 2. 界面结构

在应用左侧全局菜单中新增“知识库”一级入口。进入知识库后，右侧主界面采用三栏布局：

1. **文档目录**：显示“全部笔记”和文件夹列表；可新建、置顶、重命名或删除普通文件夹。
2. **文档列表**：按更新时间展示当前目录下的文档，提供关键词搜索及单篇文档操作菜单。
3. **文档内容**：显示并编辑 Markdown 笔记；可新建笔记、保存或删除当前文档。

知识库内部的“全部笔记”和文件夹属于页面局部导航，不增加为应用左侧的多个全局菜单。

## 3. 笔记与文件导入

### Markdown 笔记

- 可新建笔记并编辑标题、正文和所属文件夹。
- 保存时将正文写入独立的 Markdown 文件，并更新本地索引。
- 可按标题、文件名、文件夹、来源名称、标签及正文内容搜索。
- 删除笔记前需要确认；若是导入文档，会同时删除知识库内的提取内容和受管理的原始附件。

### 导入文档

支持导入 `.md`、`.markdown`、`.txt`、`.json`、`.csv`、`.html`、`.pdf`、`.docx`、`.xlsx`、`.xls`、`.pptx`。导入既可通过文件选择器批量选择，也可将文件拖入知识库页面。

导入时，程序把原文件复制到知识库自己的 `originals` 目录，并解析可检索文本写入对应的 Markdown 内容文件。界面将其作为带来源信息的导入文档展示。删除知识库条目只删除知识库内的附件副本，不删除用户选择的外部原文件。

导入目标目录遵循当前选择：选中具体文件夹时放入该文件夹；选中“全部笔记”时放入“默认”文件夹。

## 4. 文件夹管理

- 初始化时自动确保固定的“默认”文件夹存在；它不能重命名、置顶或删除。
- 新建普通文件夹时名称必填、去除首尾空格，最多 7 个 Unicode 字符，并且不能与已有文件夹重名。
- 普通文件夹支持置顶/取消置顶、行内重命名和删除。重命名同样校验名称长度及重名。
- 删除文件夹前明确提示：目录中的笔记、导入文档及其知识库内原始附件会一起删除，且操作不可恢复。
- 文件夹顺序为“默认”、已置顶文件夹、其他文件夹。
- 在具体文件夹内新建笔记时，新笔记归属当前文件夹；在“全部笔记”下新建时归入“默认”。
- 从旧索引迁移时，“未分类”和“导入文件”归属会迁移到“默认”；已有普通文件夹会按笔记归属补建记录。

## 5. 文档移动、复制与删除

文档列表每项的 `⋯` 菜单包含“移动到…”、“复制到…”和“删除”。移动和复制共用目标文件夹选择窗口，当前所在文件夹不会列为可选目标，“默认”可以作为目标。

- **移动**：只更新文档的文件夹归属，保留文档 ID、正文和附件。完成后切换到目标目录并选中该文档。
- **复制**：创建新的文档 ID 和 Markdown 文件，复制标题、正文和元数据。若源文档有关联的知识库原始附件，也会复制附件并让副本指向独立副本。允许同一文件夹内存在同名文档。
- **删除**：使用确认窗口。删除导入文档时同时删除索引记录、提取内容和知识库管理的附件副本；外部原文件不受影响。

## 6. Agent 集成

知识库能力通过内置工具提供给 Agent：

| 工具 | 用途 | 权限 |
| --- | --- | --- |
| `search_knowledge` | 按问题或关键词搜索知识库条目，返回标题、来源和 ID | 读取 |
| `read_note` | 根据条目 ID 读取完整内容，通常先搜索再读取 | 读取 |
| `create_note` | 在知识库中创建 Markdown 笔记，可指定文件夹 | 写入 |
| `update_note` | 根据 ID 更新已有 Markdown 笔记 | 写入 |

写入工具按客户端工具权限流程执行。导入附件由知识库界面处理；Agent 搜索和读取的是已保存的知识库条目及其提取文本。

## 7. 当前本地存储

知识库数据位于 Electron `app.getPath('userData')` 下的 `knowledge-base` 目录：

```text
knowledge-base/
├── notes/                 # 笔记及导入文档的 Markdown 内容文件
├── originals/             # 导入文件的知识库内副本
└── knowledge-index.json   # 文件夹和文档元数据索引
```

每篇笔记/导入文档使用独立 ID 和 `.md` 文件；JSON 索引记录标题、文件夹、类型、时间、标签及原始附件路径等信息。当前关键词搜索遍历索引，并在需要时读取 Markdown 正文匹配，最多返回 200 条。当前版本尚未使用 SQLite、FTS5 或 `sqlite-vec`，也没有语义向量检索。

## 8. 主进程与界面通信

知识库由 Electron 主进程中的存储模块负责文件和索引操作；`main` 注册 IPC 处理器，`preload` 将受控 API 暴露给渲染进程，React 知识库页面调用这些 API。接口覆盖笔记列表、读取、新建、更新、删除、移动、复制、文件导入，以及文件夹列表、新建、重命名、置顶和删除。

## 9. 测试与后续方向

知识库测试覆盖笔记创建/更新/搜索/删除、文本文件导入和原件保存、指定文件夹导入、移动与复制、附件清理、文件夹生命周期及旧索引迁移。最近一次实现验证记录为：`npm test` 的知识库相关测试通过，`npm run build` 通过。

后续若本地数据量或检索性能成为实际问题，可再评估 SQLite/FTS5 或可选语义检索；这些不属于当前已交付功能。
