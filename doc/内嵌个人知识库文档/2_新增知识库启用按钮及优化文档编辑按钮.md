# 新增知识库启用按钮及优化文档编辑按钮

## 1. 功能概述

本次优化围绕两个场景展开：

1. 在对话输入区增加“使用知识库”开关，让用户决定当前对话是否使用个人知识库内容进行辅助回答。
2. 优化知识库文档和文件夹的三个点操作菜单，点击其他区域时自动关闭，避免操作菜单持续遮挡界面。

## 2. 对话启用知识库

### 2.1 开关位置

“使用知识库”按钮位于对话输入区底部工具栏，与项目目录和工具权限模式并列显示。

- 关闭状态显示为灰色。
- 开启状态使用主题色，并显示“开”。
- 发送或生成过程中按钮不可切换。
- 鼠标悬停可看到提示：开启后发送消息前会先检索本地知识库。

### 2.2 保存范围

开关状态按对话独立保存：

- 新建对话默认关闭。
- 不同对话可以使用不同的知识库开关状态。
- 旧版本会话没有该字段时自动按关闭处理。
- 切换会话后恢复该会话最近保存的状态。

## 3. 自动检索流程

当“使用知识库”开启时，发送消息会执行以下流程：

1. 使用用户原始问题检索知识库。
2. 最多选取 5 条匹配内容。
3. 读取对应 Markdown 内容，并限制总上下文长度。
4. 将标题、文件夹、来源和正文片段作为参考上下文提供给模型。
5. 模型根据用户问题判断内容相关性后生成回答。

知识库正文会被标记为参考资料，其中的指令不会被当作系统指令执行。自动注入的上下文只在 Agent 内部使用，不会写入用户会话消息，避免聊天记录重复保存检索内容。

如果没有匹配内容，继续执行普通对话；如果检索失败，也会自动降级为普通对话，不阻断用户请求。

界面会显示“正在检索知识库”状态，检索完成后继续显示模型生成状态。

## 4. 关闭知识库时的限制

当开关关闭时，本次 Agent 请求不会自动检索知识库，并且会从模型可用工具中移除：

- `search_knowledge`
- `read_note`

同时主进程还会对这两个工具执行二次拦截，防止模型通过异常或手动构造的工具调用绕过界面开关。

以下写入工具不受该开关影响：

- `create_note`
- `update_note`

也就是说，关闭检索不代表禁止用户明确要求 Agent 创建或更新知识库笔记。

## 5. 数据与接口变更

### 会话数据

会话对象增加：

```ts
useKnowledgeBase: boolean
```

并在会话管理中提供：

```ts
setUseKnowledgeBase(enabled: boolean): void
```

### Agent 请求

Electron `send-message` 请求增加：

```ts
useKnowledgeBase?: boolean
```

该参数由 React 对话界面经 `useChat`、Preload 和 IPC 传递到主进程 Agent 循环。

### 知识库检索接口

知识库存储模块增加面向 Agent 的上下文检索能力：

```ts
retrieveContext(query: string, limit = 5)
```

返回条目 ID、标题、文件夹、来源和正文片段。

## 6. 文档编辑菜单优化

### 6.1 适用菜单

以下操作菜单都支持点击外部自动关闭：

- 文档列表每行右侧的三个点菜单。
- 文件夹列表每行右侧的三个点菜单。

### 6.2 交互规则

打开菜单后，点击以下区域会立即关闭菜单：

- 右侧文档编辑区。
- 文档搜索框。
- 文档列表空白区域。
- 文件夹目录区域。
- 知识库标题和其他页面区域。

点击菜单自身或菜单内的“移动到…”、“复制到…”、“删除”、“置顶”、“重命名”等操作时不会被外部点击逻辑误关闭，原有操作继续执行。

点击另一个菜单按钮时，旧菜单会关闭，只保留新菜单。

移动、复制、删除和新建文件夹使用的模态窗口属于独立交互，不会因为普通菜单的外部点击监听而被取消。

### 6.3 技术实现

知识库页面根容器注册 `pointerdown` 监听，并通过元素选择器判断点击是否发生在菜单按钮或菜单内容内部：

```text
.knowledge-note-menu
.knowledge-note-menu-button
.knowledge-folder-menu
.knowledge-folder-menu-button
```

点击其他区域时清除文档菜单和文件夹菜单的状态。组件卸载时移除监听，避免事件泄漏。

使用 `pointerdown` 可以同时覆盖鼠标和触摸操作，并在点击编辑区后及时清除菜单。

## 7. 涉及模块

- `src/types/chat.ts`：增加会话知识库开关字段。
- `src/hooks/useConversations.ts`：保存和切换每个会话的开关状态。
- `src/hooks/useChat.ts`：发送和重试时传递开关。
- `src/components/Chat.tsx`：新增“使用知识库”按钮和检索状态显示。
- `src/components/KnowledgeBase.tsx`：增加菜单点击外部关闭逻辑。
- `electron/agentLoop.ts`：执行自动检索、注入上下文和过滤知识库读取工具。
- `electron/knowledge.ts`：提供上下文检索方法。
- `electron/main.ts`、`electron/preload.ts` 及类型声明：传递请求参数。
- `shared/task.ts`：增加 `retrieving_knowledge` 任务状态。

## 9. 使用说明

需要使用个人知识库回答问题时，在对话输入区打开“使用知识库”，再发送问题。普通闲聊或不希望参考本地资料时保持关闭即可。

在知识库页面中，点击文档或文件夹右侧的三个点进行移动、复制、删除、置顶或重命名；点击页面其他位置即可关闭操作菜单。
