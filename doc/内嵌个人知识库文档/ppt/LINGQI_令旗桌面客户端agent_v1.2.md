# LINGQI（令旗）桌面客户端 Agent v1.2

## 05 内嵌个人知识库

本页在原 v1.1 演示文稿“后续规划”之后新增，介绍 v1.2 已落地的内嵌个人知识库功能。知识库面向个人使用、本地优先，嵌入令旗桌面客户端，为 Agent 提供可管理、可检索、可控的本地资料上下文。

### 本页内容

| 模块 | 说明 |
| --- | --- |
| 本地优先 | 使用 Markdown 保存笔记，使用 JSON 保存文件夹和文档索引，资料保存在本机。 |
| 文件导入 | 支持 Markdown、TXT、PDF、DOCX、XLSX、PPTX 等常见文件导入，并保留知识库内的原始附件副本。 |
| RAG 检索 | 可按对话开启或关闭知识库；开启后发送问题前自动检索，最多补充 5 条相关内容。 |
| 三栏管理 | 知识库页面分为文档目录、文档列表和文档内容编辑区。 |
| 文件操作 | 支持新建、编辑、移动、复制、删除文档，以及新建、置顶、重命名和删除文件夹。 |
| 安全可控 | 关闭知识库开关时不执行检索；删除知识库条目不会删除用户外部原文件。 |

### 对话知识库开关

- “使用知识库”开关位于对话输入区底部工具栏。
- 开关状态按对话保存，新对话默认关闭。
- 开启后，Agent 发送请求前使用用户原始问题检索本地知识库。
- 检索内容只作为模型参考上下文，不会写入聊天记录。
- 关闭时禁止知识库搜索和读取工具，但不影响创建或更新知识笔记。

### 知识库页面

- 左侧文档目录显示“全部笔记”和文件夹。
- 中间文档列表支持搜索和三个点操作菜单。
- 右侧文档内容区支持 Markdown 编辑和保存。
- 文档或文件夹的三个点菜单在点击编辑区、搜索框、目录或其他外部区域时自动关闭。

### 版本说明

当前版本采用 Markdown 文件、原始附件目录和 `knowledge-index.json` 索引，尚未接入 SQLite、FTS5 或 `sqlite-vec` 语义检索。后续可根据本地数据量和检索性能需求继续扩展。
