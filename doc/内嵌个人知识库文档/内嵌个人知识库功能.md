# 内嵌个人知识库功能

## 1. 功能定位

内嵌个人知识库是 Agent 桌面客户端中的本地知识管理空间，帮助用户沉淀个人资料、整理文档，并在对话中调用这些内容辅助回答。

它面向个人长期使用，强调本地优先、轻量和可控。用户可以把零散的笔记、工作资料和参考文件集中管理，也可以根据需要决定某一次对话是否使用知识库。

知识库当前不面向多用户协作、云端同步或复杂权限管理，重点是建立“资料保存、快速查找、Agent 辅助使用”的个人闭环。

## 2. 整体界面

知识库作为应用左侧菜单中的一级入口。点击“知识库”后，右侧主区域切换为知识库工作界面。

知识库内部采用三栏结构：

- **左侧文档目录**：显示全部笔记和文件夹，用于切换资料范围。
- **中间文档列表**：显示当前目录中的文档，提供搜索和文档操作入口。
- **右侧文档内容**：查看和编辑当前选中的 Markdown 笔记或导入文档内容。

“知识库”属于应用全局菜单；“全部笔记”“默认”以及用户创建的其他文件夹属于知识库页面内部导航，不会增加为多个全局菜单项。

## 3. 文档管理

用户可以在知识库中直接新建 Markdown 笔记，填写标题和正文，并选择所属文件夹。保存后，笔记会出现在对应目录的文档列表中。

文档列表支持按标题、正文、来源和文件夹进行关键词搜索，方便从大量个人资料中快速找到目标内容。

每篇文档右侧提供三个点操作菜单：

- **移动**：将文档归入其他文件夹，原文档内容和附件保持不变。
- **复制**：生成一份独立副本，副本拥有独立文档记录；如果原文档有关联附件，附件也会生成独立副本。
- **删除**：删除当前知识库文档。导入文档删除时，还会删除知识库内部保存的提取内容和附件副本。

## 4. 文件导入

知识库支持导入常见文本和办公文档，包括：

- Markdown、TXT、JSON、CSV、HTML。
- PDF、DOCX、XLSX、PPTX 等常见办公文件。

导入方式包括文件选择器批量导入和直接拖拽导入。导入后，系统会保留一份知识库内部的原始文件副本，同时提取其中的文本内容，用于搜索和 Agent 阅读。

导入目标遵循当前选择的目录：

- 在“全部笔记”下导入，文件进入“默认”文件夹。
- 在具体文件夹下导入，文件进入当前选中的文件夹。

用户电脑中原始位置的文件不会因为知识库删除操作而被删除。

## 5. 文件夹管理

知识库初始化时会自动创建“默认”文件夹。“默认”是系统保留目录，不能重命名、置顶或删除，用于承接没有指定目录的内容。

普通文件夹可以由用户按主题、项目或用途创建。普通文件夹支持：

- 新建文件夹。
- 置顶或取消置顶。
- 修改文件夹名称。
- 删除文件夹及其内容。

新建和重命名时，文件夹名称必须填写，不能超过 7 个字符，也不能与已有文件夹重名。删除文件夹前会明确提示，确认后会一并删除该文件夹下的笔记和知识库内部附件。

文件夹展示顺序为：默认文件夹、已置顶文件夹、普通文件夹。

## 6. 文档编辑菜单体验优化

文档列表和文件夹列表都提供三个点操作入口，用于集中放置移动、复制、删除、置顶和重命名等操作。

菜单打开后，点击文档编辑区、搜索框、目录区、列表空白处或页面其他区域，菜单会自动关闭。这样可以避免操作菜单长期停留并遮挡文档内容。

当用户点击另一个菜单按钮时，原菜单会自动收起，只保留当前操作菜单。点击菜单内部的具体操作不会被外部点击逻辑误关闭，移动、复制、删除和重命名等流程保持正常。

移动、复制、删除以及新建文件夹使用的弹窗属于独立交互，不会因为普通菜单的自动关闭而被取消。

## 7. 对话中启用知识库

对话输入区增加“使用知识库”按钮，用户可以决定当前对话是否参考本地知识库内容。

- 开关状态按对话独立保存。
- 新对话默认关闭。
- 开启后，发送问题前会先检索本地知识库。
- 关闭后按照普通对话流程处理。
- 对话生成或检索过程中不能切换，避免请求状态不一致。

这个设计让用户可以根据问题类型灵活选择：需要参考个人资料时打开，不希望本地资料参与时保持关闭。

## 8. 知识库辅助回答流程

开启知识库后，对话会按照以下流程工作：

```text
用户提出问题
    ↓
判断是否开启“使用知识库”
    ↓
检索本地相关文档
    ↓
提取最多 5 条相关内容
    ↓
作为参考资料交给 Agent
    ↓
Agent 结合问题生成回答
```

检索结果包括文档标题、所属文件夹、来源和正文片段。知识库内容会被明确标记为参考资料，其中的文字不会覆盖系统指令，也不会被直接当作操作命令执行。

如果没有检索到相关内容，对话仍然可以正常进行；如果检索过程出现问题，系统会自动降级为普通对话。自动检索使用的上下文不会重复写入聊天记录，避免会话内容膨胀。

## 9. Agent 可执行能力

Agent 可以在用户授权的范围内使用知识库能力：

- 搜索个人知识库。
- 读取指定文档的完整内容。
- 创建新的知识笔记。
- 更新已有知识笔记。
- 根据当前问题引用本地资料辅助回答。

关闭“使用知识库”时，Agent 不会自动检索，也不能通过搜索或读取工具绕过开关。该开关主要控制知识库读取和检索，不影响用户明确要求 Agent 创建或更新知识笔记。

## 10. 数据安全与本地存储

知识库采用本地优先的存储方式：

- 用户笔记以 Markdown 文件形式保存。
- 导入文件保存在知识库内部的原始文件副本目录。
- 索引记录标题、文件夹、来源和更新时间等信息。
- 删除知识库中的导入文档时，只删除知识库内部副本，不删除用户电脑原始位置的文件。

当前版本使用关键词检索。SQLite、FTS5、`sqlite-vec` 和语义向量检索属于后续可评估的优化方向，不是当前版本的已实现能力。

## 11. 功能价值

内嵌个人知识库为 Agent 客户端提供了一个轻量的个人资料中心，主要价值包括：

- 让个人资料与 Agent 对话形成闭环。
- 降低重复查找和重复说明的成本。
- 将零散文件逐步沉淀为可管理、可检索的知识内容。
- 通过开关控制知识库是否参与当前对话，兼顾灵活性和隐私控制。
- 保持本地化、轻量化和可迁移，适合个人长期使用。
