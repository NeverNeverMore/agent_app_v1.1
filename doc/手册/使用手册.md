# LINGQI(令旗)桌面客户端 Agent 使用手册

## 1. 产品简介

令旗桌面客户端 Agent 是一个基于 Electron 的桌面智能助手。用户可以在本地选择项目目录，与大模型进行连续对话，并让 Agent 在受控范围内读取项目文件、计算数据、访问网页或写入文件。

当前版本的核心能力包括：

- 流式对话：模型回答会实时显示；
- 会话管理：新建、切换、重命名和删除历史会话；
- 项目管理：将会话关联到本地项目目录，并按项目分组展示；
- 文件附件：上传文本、图片、PDF、Word、Excel 和 PowerPoint 文件；
- 内置工具：文件列表、文件读取、文件写入、计算器、当前时间和 HTTP GET；
- 权限控制：写入文件时请求批准，或切换为完全访问权限；
- MCP：连接本机通过 `stdio` 启动的 MCP Server；
- Skill：按会话启用 Markdown 格式的工作规范。

> 当前客户端不负责大模型推理，也不内置独立的知识库或 OpenViking 服务。模型和外部服务由用户在设置中配置。

## 2. 首次使用

### 2.1 配置模型接口

1. 打开客户端，点击右上角“设置”。
2. 填写 API 密钥。
3. 选择协议：
   - `OpenAI Compatible`：适用于兼容 `/chat/completions` 的接口；
   - `Anthropic Messages`：适用于 Anthropic `/v1/messages` 接口。
4. 填写 API 请求地址和模型 ID。
5. 点击“检测连通”。
6. 检测通过后点击“保存”。

默认配置为：

| 配置项    | 默认值                              |
| ------ | -------------------------------- |
| API 地址 | `https://api.kimi.com/coding/v1` |
| 模型     | `kimi-code-plan`                 |
| 协议     | OpenAI Compatible                |

检测 OpenAI 兼容接口时，客户端访问 `${baseUrl}/models`；部分网关没有该接口时，检测可能失败，但实际聊天接口仍可能可用。Anthropic 协议使用一次最小消息请求进行检测。

### 2.2 关联项目目录

在聊天页面底部点击文件夹按钮，选择项目目录。关联后：

- Agent 可以使用 `file_list` 和 `file_read` 读取该目录内的文件；
- 默认写入工具只能写入项目目录内部；
- 项目目录会成为会话上下文的一部分；
- 首条消息发送后，该会话会归入对应项目分组。

如果不关联项目目录，文件工具无法读取项目文件，写入工具也无法正常使用。

## 3. 开始对话

- 在底部输入框输入问题，按 `Enter` 发送；
- 按 `Shift + Enter` 换行；
- 生成过程中点击停止按钮可取消当前任务；
- 任务失败后可点击重试；
- 模型调用工具时，页面会显示工具执行状态。

常见提问示例：

```text
请列出当前项目的目录结构，并说明主要模块用途。
请读取 src/App.tsx，找出设置面板的入口。
请计算本季度各月份的合计金额。
请查询这个 HTTP 接口并总结返回结果。
```

## 4. 会话和项目

左侧栏提供以下操作：

- “新对话”：创建空白会话；
- 点击会话：切换到对应历史记录；
- 双击会话标题或点击编辑按钮：重命名；
- 点击删除按钮：删除会话；
- 点击项目标题：折叠或展开项目下的会话；
- 点击项目编辑按钮：修改项目显示名称。

会话、项目和 API 配置保存在当前客户端的 `localStorage` 中。它们属于当前操作系统用户和当前应用数据，不会自动同步到服务器。清理应用数据后，这些内容可能丢失。

## 5. 使用附件

点击回形针按钮，或将文件拖入聊天区域，可添加附件。当前支持：

- 文本：TXT、Markdown、JSON、CSV、TS、TSX、JS、JSX、CSS、HTML、Python、Java；
- 图片：PNG、JPG、JPEG、WEBP；
- PDF；
- Word：DOCX；
- Excel：XLSX、XLS；
- PowerPoint：PPTX。

限制如下：

| 限制项      | 当前值           |
| -------- | -------------:|
| 单次附件数量   | 最多 5 个        |
| 单个附件大小   | 最大 20 MB      |
| 单个附件提取文本 | 最多 100,000 字符 |
| 单次附件合计文本 | 最多 180,000 字符 |

文档会在本地解析后加入本次请求上下文。图片会转换为 data URL，并要求当前模型接口支持多模态输入。附件不会写入项目目录，任务结束后默认延迟清理，应用启动时也会清理长期遗留的临时附件。

## 6. 工具权限

聊天输入区底部可以选择权限模式：

### 请求批准

这是默认模式。读取类工具可以直接执行；写入文件时会弹出审批卡片，显示目标路径、是否覆盖、内容长度和内容预览。用户可以批准或拒绝。

### 完全访问权限

写入项目文件时不再弹出审批卡片。该模式权限更高，应只在明确需要自动修改文件时使用。

当前版本的高危工具不会执行。即使模型要求执行，也会返回权限拒绝结果。

## 7. MCP 和 Skill

### MCP

在左侧 MCP 页面添加本机 MCP Server，填写服务名称、启动命令、参数、环境变量和启用状态。客户端只支持通过 `stdio` 启动的本地 MCP Server。连接成功后，Server 提供的工具会出现在工具列表中。

MCP 配置保存在 Electron 的用户数据目录下的 `mcp-servers.json` 中。请谨慎填写启动命令和环境变量，因为 MCP Server 以当前操作系统用户权限运行。

### Skill

Skill 是包含 `SKILL.md` 的 Markdown 指令包，不会直接执行脚本或绕过工具权限。Skill 可以来自：

- 全局目录：Electron 用户数据目录下的 `skills`；
- 项目目录：项目目录下的 `.agent/skills`。

在 Skills 页面刷新并勾选 Skill 后，它的正文会加入当前会话的系统提示词。项目 Skill 与全局同名时，项目 Skill 优先。

## 8. 常见问题

### 检测连通失败

检查 API 地址、API 密钥、模型 ID 和协议是否匹配。OpenAI 兼容接口还要确认服务是否提供 `/models`。如果目标网关不提供该接口，可以直接保存设置后测试聊天。

### Agent 无法读取文件

确认已经关联项目目录，并且文件路径是项目目录内的相对路径。客户端会拒绝 `../` 越界路径和指向项目外部的符号链接。

### 写入操作没有执行

在“请求批准”模式下，需要在审批卡片中点击“批准”。如果请求被拒绝、取消、过期或参数发生变化，写入不会执行。

### 重启后看不到会话

会话保存在 `localStorage`。如果应用数据被清理、换了系统用户或使用了不同的客户端数据目录，原会话不会出现。
