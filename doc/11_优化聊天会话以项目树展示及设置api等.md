# 优化聊天会话以项目树展示及设置 API 等

## 1. 功能概述

本次优化围绕聊天会话历史和 API 配置体验展开：

- 左侧会话历史按项目树组织，会话归属于项目。
- 项目与目录建立关联，项目名称默认取目录最后一级名称。
- 选择目录时只更新当前会话草稿，不立即创建项目。
- 用户首次发送消息后，才创建或复用项目并将会话归档到项目下。
- 新建会话只创建空草稿，不在左侧历史中插入空记录。
- 侧栏移除冗余计数和会话移动控件。
- 项目支持内联重命名。
- API 配置保存后显示短暂的“保存成功”提示。

## 2. 会话与项目生命周期

### 2.1 空草稿

空草稿是尚未发送过用户消息的当前会话，具有以下特点：

- 可以选择或切换项目目录。
- 可以设置权限模式、技能等会话配置。
- 不显示在左侧会话历史中。
- 不计入会话历史数量。
- 新建会话时只替换当前空草稿，不写入历史记录。

### 2.2 首次发送归档

首次发送消息时，系统将当前空草稿转换为正式会话：

1. 检查当前会话是否选择了目录。
2. 如果目录存在，取目录最后一级作为项目名称。
3. 使用规范化后的目录路径查找已有项目。
4. 找到相同目录项目时复用该项目。
5. 找不到时创建新项目，并将当前会话归入该项目。
6. 如果没有选择目录，则将会话归入“未分类”项目。
7. 会话标题根据首条用户消息生成，后续消息继续更新会话内容和更新时间。

例如：

```text
D:\\tmp\\test
```

首次发送消息后，左侧会出现名为 `test` 的项目，当前会话显示在该项目下。

### 2.3 目录切换

在发送消息前连续选择多个目录时，只保留最后一次选择的目录。目录选择动作本身不会创建项目，避免左侧出现没有实际会话内容的项目节点。

## 3. 项目树交互

### 3.1 项目显示

- 项目按最近活跃时间排序。
- 只有包含正式会话的项目才显示在左侧。
- 项目可以展开或收起。
- 项目名称默认使用关联目录的最后一级名称。
- 项目目录路径通过悬浮提示保留完整路径信息。

### 3.2 会话显示

- 会话按最近更新时间排序。
- 空草稿不显示。
- 会话支持选中、重命名和删除。
- 会话历史标题后不再显示总会话数。
- 项目标题后不再显示项目内会话数量。
- 会话行不再提供“移动到项目”下拉控件。

### 3.3 项目重命名

项目标题右侧提供编辑按钮。进入编辑状态后：

- 项目名称替换为输入框。
- 按 `Enter` 保存。
- 输入框失去焦点时保存。
- 按 `Escape` 取消并恢复原名称。
- 空名称不会提交。
- 重命名只修改项目展示名称，不修改实际目录名称或目录绑定关系。
- 保存后项目树立即更新，并通过本地会话状态持久化。

## 4. 数据结构

### 4.1 Conversation

会话继续保留原有字段，并增加项目归属字段：

```ts
interface Conversation {
  id: string
  title: string
  messages: Message[]
  projectFolder: string
  projectId: string
  permissionMode: PermissionMode
  enabledSkillIds: string[]
  createdAt: number
  updatedAt: number
}
```

### 4.2 Project

```ts
interface Project {
  id: string
  name: string
  folder: string
  createdAt: number
  updatedAt: number
}
```

### 4.3 持久化

项目、会话和当前草稿状态继续保存在现有的 `chat-conversations-state` localStorage 键中。

兼容策略如下：

- 兼容旧版只有 `projectFolder` 的会话。
- 旧会话首次加载时按目录建立项目归属。
- 没有目录的正式会话进入“未分类”项目。
- 没有用户消息的旧空会话会被视为草稿，不显示在历史中。
- 目录路径比较前会统一斜杠、去除末尾分隔符并统一大小写，避免同一目录产生重复项目。

## 5. API 配置保存反馈

设置抽屉中的保存按钮仍然将 API Key、请求地址、模型和协议保存到本地配置。

保存成功后：

- 在设置抽屉底部显示带勾选图标的“保存成功”。
- 提示以状态文本形式提供无障碍播报。
- 提示约 2.2 秒后自动隐藏。
- 修改任意配置字段时清除旧提示。
- 重新打开设置时清除旧提示。
- 执行 API 连接测试时清除旧提示。
- 保存成功提示只代表本地配置已写入，不代表 API 连接测试成功。

## 6. 模型名称展示

当前配置中的模型名称由同一数据源提供，并显示在两个位置：

- 主对话框输入区底部。
- 请求批准卡片右侧。

模型名称过长时截断显示，完整名称可通过悬浮提示查看。模型未配置时显示统一的未知模型占位文本。

## 7. 相关实现位置

- `src/hooks/useConversations.ts`：会话、项目、草稿和首次发送归档状态管理。
- `src/components/Sidebar.tsx`：项目树、项目展开/收起、项目重命名和会话操作。
- `src/components/Chat.tsx`：目录选择、模型名称和请求批准区域。
- `src/components/Settings.tsx`：API 配置编辑和保存成功提示。
- `src/App.tsx`：页面级状态连接和组件事件绑定。
- `src/types/chat.ts`：`Conversation` 与 `Project` 类型定义。
- `src/index.css`：项目树、内联编辑和保存提示样式。
