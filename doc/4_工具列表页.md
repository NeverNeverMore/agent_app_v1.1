# 工具列表页

> 版本：V1.1 ｜ 日期：2026-08-24 ｜ 状态：已完成开发，构建通过

## 一、功能概述

将左侧导航「工具」占位页替换为真实工具列表页：主进程 ToolRegistry 改为共享单例，工具定义扩展展示元数据，通过 IPC 动态生成列表，前端按来源分组只读展示。不包含启停开关，file_write 与用户确认流程属于 V2 范围。

## 二、改动文件

| 文件 | 改动 |
|---|---|
| `shared/tools.ts` | 新增 `ToolSource`、`ToolMeta`（名称/展示名/描述/权限/来源/分类/使用条件） |
| `electron/tools/types.ts` | `ToolDefinition` 扩展 `displayName`、`source`、`category`、`requirements` |
| `electron/tools/builtins.ts` | 4 个内置工具补充元数据；file 工具声明「需要关联项目文件夹」 |
| `electron/tools/registry.ts` | 新增 `listMeta()`，从注册表动态生成元数据 |
| `electron/tools/index.ts` | 新增 `getToolRegistry()` 共享单例，agentLoop 与 list-tools 复用 |
| `electron/agentLoop.ts` | 改用共享单例，不再每次会话新建注册表 |
| `electron/main.ts` | 新增 `ipcMain.handle('list-tools')` |
| `electron/preload.ts` / `src/types/electron.d.ts` | 暴露 `listTools(): Promise<ToolMeta[]>` |
| `src/components/ToolList.tsx` | 工具列表页组件：按来源分组、卡片只读展示 |
| `src/App.tsx` | tools 占位页替换为 `ToolList` |
| `src/index.css` | 工具卡片样式，与消息内工具卡片风格一致 |
